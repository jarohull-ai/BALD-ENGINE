# bse-providers

[![Crates.io](https://img.shields.io/crates/v/bse-providers?style=flat-square)](https://crates.io/crates/bse-providers)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

Multi-source search provider adapters for the **BALD Sovereign OSINT Engine**.

## Features

- **DuckDuckGo Live Crawler**: Direct HTML web crawler with zero API keys or accounts required.
- **SearXNG & Brave**: Federated open-web search integrations with JSON schema parsing.
- **Wikipedia API**: Multi-language encyclopedic background lookup (PL & EN).
