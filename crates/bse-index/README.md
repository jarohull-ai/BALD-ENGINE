# bse-index

[![Crates.io](https://img.shields.io/crates/v/bse-index?style=flat-square)](https://crates.io/crates/bse-index)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

Local full-text search indexing powered by Tantivy (BM25) for the **BALD Engine**.

## Features

- **Embedded Search**: Zero-dependency local indexing of fetched web documents.
- **BM25 Scoring**: Fast lexical ranking optimized for investigative research queries.
- **Idempotent Upsert**: De-duplicates documents by canonical URL hash.
